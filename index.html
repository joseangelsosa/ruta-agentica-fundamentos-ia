    Etapa 1 de 3

    Git: una red de seguridad para experimentar

    Durante el curso un agente modificará archivos. Para aprender con tranquilidad necesitas una forma de guardar puntos de recuperación. Git es una herramienta que registra versiones del trabajo. Un repositorio es la carpeta de un proyecto de software cuyo historial gestiona Git; no significa necesariamente que esté publicado en Internet.

    Carpeta del proyecto→Cambio pequeño→Revisar diferencias→Commit

    Un commit es una fotografía identificable de cambios guardados en el historial. Una rama permite trabajar en una línea separada sin mezclar inmediatamente los cambios. Una PR o pull request es una solicitud para revisar e integrar cambios; no la necesitas para cada ejercicio local.

    1. Instala Git si aún no lo tienes desde git-scm.com/downloads.
    2. En un repositorio de práctica, consulta git status para ver qué ha cambiado.
    3. Haz una modificación pequeña y consulta git diff para revisarla.
    4. Con ayuda del agente, guarda un commit solo cuando comprendas sus cambios. No subas secretos ni datos personales.
    ! ImportanteEvita experimentos destructivos. No ejecutes comandos de borrado, restablecimiento forzado ni subida al remoto sin entender sus consecuencias. Practica con datos ficticios.

    01 Fundamentos del agente

    Un agente no es simplemente un chat que responde

    Un agente de desarrollo puede examinar archivos, proponer cambios y, si sus herramientas y permisos se lo permiten, ejecutarlos. La conversación orienta su trabajo; el conserva los resultados que otras personas necesitan revisar.

    Por qué estamos aquí · Comprender qué hace realmente la IA

    Antes de pedirle trabajo a un agente, conviene distinguir entre conversar sobre una solución y permitir que una herramienta lea, modifique o pruebe archivos. La diferencia está en las acciones y en las evidencias.

    Etapas de este capítulo · la línea indica tu posición. Puedes elegir cualquier etapa.

    Qué es realmente un modelo de IA

    Un es un sistema entrenado para identificar patrones en grandes cantidades de información y generar texto, código u otras salidas a partir de lo que recibe. No consulta automáticamente una fuente fiable cada vez que responde: puede producir una explicación convincente y estar equivocado.

    Lo que aprendió durante su entrenamiento

    Le ayuda a reconocer estructuras, conceptos y formas de resolver tareas, pero no garantiza que una afirmación sea correcta o esté actualizada.

    Lo que le damos durante la tarea

    El requisito, los archivos disponibles, las reglas y los resultados de las herramientas forman su contexto de trabajo. Puede cambiar entre sesiones.

    Un agente combina ese modelo con herramientas y reglas. Por eso una respuesta escrita y una acción ejecutada son cosas distintas: lo primero es texto; lo segundo necesita una herramienta, permisos y una evidencia.

    ✦ Idea clave que te llevasLa fluidez no demuestra exactitud. Siempre que el resultado importe, pide pruebas, verifica fuentes y comprueba el comportamiento real.
